## ✨ Features & Architecture

- **Split-Curtain Preloader**: Editorial agency loading sequence with 0–100% counter and curtain reveal.
- **Custom Awwwards Cursor**: Fluid follower circle with hover expansion on interactive links and buttons.
- **Silky Smooth Scroll**: Powered by Lenis, perfectly synchronised with GSAP ScrollTrigger.
- **Monumental Hero**: Staggered typography clip-path reveal and parallax architectural imagery.
- **Horizontal Works Carousel**: Editorial showcase of residential villas, interior ateliers, and brutalist residences.
- **Interactive Services Matrix**: Dark accordion layout with floating render hover previews.
- **Interactive Testimonials**: Multi-client review carousel with portrait reveals.
- **Infinite Marquee**: Seamless looping partner and client logo reel.
- **Animated Statistics**: Numeric counter animations for years, projects, clients, and countries.
- **Process & Skill Gauges**: Step-by-step design-to-execution methodology with animated software proficiency meters (3ds Max, Lumion, Photoshop, SketchUp, AutoCAD).
- **Insights & Editorial**: Architectural publications and monographs.
- **Luxury Colophon & Footer**: Direct WhatsApp inquiry, email contact, and quick navigation.

## 🛠️ Technology Stack

- **Framework:** Next.js 14 (App Router)
- **Animation Engine:** GSAP 3 + ScrollTrigger
- **Smooth Scrolling:** `@studio-freight/lenis`
- **Styling:** Custom Vanilla CSS Design System (Atelier / Archidex luxury aesthetic)
- **Fonts:** Playfair Display, Outfit, Cormorant Garamond via Google Fonts

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm run start
```
